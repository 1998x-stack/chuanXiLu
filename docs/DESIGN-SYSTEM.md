# 视觉系统：明代书院、宣纸与朱印

## 气质

以书院文献的静气为原则：阅读优先、结构克制，避免厚重的仿古边框和炫目动画。重点突出古文句子与少量经过审慎标注的现代解释。

## 色彩

- 宣纸米白：#f3efe6，正文卡 #fffdf7
- 墨绿黑：#242c29
- 朱砂红：#6d342b
- 古铜色：#ab8954
- 暗色主题采用深绿黑底与柔和文字，不使用纯黑/纯白强对比

## 字体与布局

优先宋体/思源宋体，系统字体兜底；辅助控制用系统 sans。正文默认19px，行高约2.1；桌面采用书目左栏与正文右区，小屏上下排列。导航始终保持可访问焦点和足够的点击区域。

## 视觉不等于学术权威

书卷式设计仅是可读性的表达；不要以印章、仿古排版暗示已完成刊本校勘。必须公开转录来源与未审校状态。
