# 底本、来源与校勘方案

## 当前真实来源

古籍正文初始数据提取自 [jeklau/chuanxilu 固定提交 1910cd1](https://github.com/jeklau/chuanxilu/commit/1910cd136f3dd30b41514e61e1a1ebac6adf5771) 的 data/b01.json — data/b22.json 中 yw 字段；篇章归属参照其 data/juan1_raw.json、juan2_raw.json、juan3_raw_n.json。源项目称底本是「殆知阁古籍库 OCR 文本」，并依通行本作了较多校订。

本站**没有移植**该项目的现代白话译文、注释、自测内容或代码。每条保留 sourceFile 与固定源提交哈希。这里的文本是现代转录稿，不是明代原版的逐字权威影像核验。

## 独立校勘的优先参照

1. [维基文库《传习录》](https://zh.wikisource.org/wiki/傳習錄) 及分卷页面；记录页面修订号、转录标点与异文。
2. [书格《传习录》影印整理](https://new.shuge.org/view/chuan_xi_lu/) 等能够辨认书页与版本信息的古籍影像；需要核实具体影印本、刻本、卷次与页叶。
3. 有明确出版信息的可靠学术校注本，用于发现疑难训诂，但不可无授权照搬现代译注。

## 校勘流水线

原始转录 → 明确见证本 → 保留异体字及行款 → 双人核验敏感字句 → 差异记录 → 审校签名和修订号 → 正文变更及回归测试。特别核查「知行」「良知」「心」「理」「格物」等高频概念和常见误引的上下文。

每次改字须记录条目ID、原文片段、改后文字、版本与页码、可访问影像/修订号、原因和审校人；未经外部证据不得把 pending 改成 verified。

## 许可与现代解释

原书属于公版，但现代断句、翻译与评注的版权归属须分别处理。新导读必须独立撰写并提供来源，不可直接搬运其他站点的现代译文。详见 [../CONTENT-ATTRIBUTION.md](../CONTENT-ATTRIBUTION.md)。

## 易混淆事项

同一句话在不同版的卷次、段落分法、标点与字形可能不同；卷上/卷下以语录为主，卷中以书信为主，但必须以每条原始语境为准。陈荣捷等后出整理体系的编号不自动成为明刻本文内原有编号。
