# 产品定义：传习录 · 知行合一

## 为什么建设

古典思想数字化容易出现三类问题：摘抄格言丢失原始问答语境；将现代释义伪装成古文；给现实问题空泛的道德训诫。本项目用可检索原典、精确出处、透明校勘状态以及可验证行动方法解决上述问题。

## 面向读者

- 研读心学的人：需要从卷、篇、条目进入上下文。
- 学习者与教育者：希望看到原文与逐句现代解释分层。
- 软件开发者：希望加载 Codex / OpenCode Skill，以真实古文思考现实选择。
- 文献校勘贡献者：希望准确记录异文与证据，而不覆盖无痕。

## MVP 的真实边界

当前 MVP 具有343条转录索引、5份序跋按语的底层数据、可读原典前端、7则选句现代示范解释、Skill 和自动化验证。完整逐句白话、图谱与可靠刊本逐字校审均列入后续阶段，不得营销成已完成。

## 功能验收

- 可按卷浏览全部343条，按原文字词、篇名检索，URL深链接可恢复。
- 注释默认隐藏；选句解释可单独展开，其他句子不出现假译文。
- 书签、字体、主题保存在本地，不上传用户阅读数据。
- 每条给出可打开的固定电子转录源链接、篇名和自有 ID。
- AI Skill 每次给出处明确的古文、通俗释义、现代边界与可执行行动。
