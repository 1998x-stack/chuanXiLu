# 传习录 · 专业工程文档

本项目不是单纯格言合集，而是具备来源、可重现索引、可验证引文及现代解释边界的数字古籍项目。

## 阅读顺序

1. [PRODUCT.md](./PRODUCT.md)：目标人群、能力范围和验收标准。
2. [CONTENT-MODEL.md](./CONTENT-MODEL.md)：上中下三卷、条目、句子与附录。
3. [TEXTUAL-SOURCES.md](./TEXTUAL-SOURCES.md)：电子底本溯源、校勘与版权。
4. [ARCHITECTURE.md](./ARCHITECTURE.md)：静态站和 Skill 数据流。
5. [READING-INTERACTION.md](./READING-INTERACTION.md)：原文与逐句释义的交互契约。
6. [DESIGN-SYSTEM.md](./DESIGN-SYSTEM.md)：书院视觉与可访问性。
7. [QA.md](./QA.md)：自动化验证与浏览器验收。
8. [DEPLOYMENT.md](./DEPLOYMENT.md)：GitHub Actions 和 GitHub Pages 部署。
9. [ROADMAP.md](./ROADMAP.md)：分阶段任务与未完成项。

所有「已实现」状态都应当有对应提交或测试证据。原文的收集完成不意味着版本校勘或现代译注工作完成。
