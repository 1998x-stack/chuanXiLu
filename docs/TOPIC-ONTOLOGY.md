# 心学主题词索引：来源、语境与误判

本项目八个主题是带原文举证的**字词导航器**，不是完成学术审查的概念知识图谱。专题按钮筛出至少包含关键词之一的原文条目；没有命中不意味着不存在相关思想，命中也不代表作者认可该观点。

| 主题 | 关键词例 | 可核对的条目 |
| --- | --- | --- |
| 知行合一 | 知行合一、知而不行 | CXL-0005 |
| 心即理 | 心即理、心外无理 | CXL-0003、CXL-0140 |
| 致良知 | 致良知、良知 | CXL-0222、CXL-0288 |
| 格物诚意 | 格物、诚意 | CXL-0006、CXL-0130 |
| 事上磨炼 | 事上磨、临事 | CXL-0023、CXL-0204 |
| 立志养心 | 立志、种德 | CXL-0016、CXL-0115 |
| 亲民与仁 | 亲民、仁民 | CXL-0001、CXL-0089 |
| 静坐与动静 | 静坐、动亦定 | CXL-0017、CXL-0204 |

示范证据的文字必须在所属条目同一句段中出现，CI 会逐条核对。语义例外至少包括：来书中的疑问（非阳明原话）、批评的对方观点（非作者认同）、编者话语（非原典正文）。统计关键词命中数量时必须标明计数方法。

后续概念图谱应建立观点、来源原句、发言者、上下文、解释者、反方观点、刊本见证的独立对象和可审计关系；每条边提供原文、页码、置信状态，评估错误归因、断章取义和漏检，而非仅计算自动生成节点数量。
