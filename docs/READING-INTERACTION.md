# 阅读交互约定

## 阅读契约

- 每次仅打开一条原典记录，其原文在上，每句现代导读在下。
- 原文按句末标点拆分，正文原样保留；每个已有注释独立按钮，初始 hidden。
- **未标注的句子保持原文，不显示假白话，也不以机器总结冒充已校勘译注。**
- 按卷及全文检索得到的是古籍文本和篇章，不代表现代知识性判定。
- 点击上一篇/下一篇只改变当前条目，不修改书籍源数据。

## 阅读工具

支持条目 URL #entry-0005、搜索、卷上/中/下筛选、收藏、上次阅读、15—27px字号和明暗主题。所有偏好仅本地保存，可能因浏览器隐私模式而不可持久化。

## 可访问性

跳转到正文链接、原生 button/input、aria-expanded/aria-controls、可见焦点、动态状态提示、键盘 Tab 导航、响应式小屏布局。CSS 尊重减少动画偏好。上线前仍需使用实际读屏与浏览器做端到端验收。

## 后续功能

序跋目录、书信和语录类型筛选、朗读、句子锚点、双版本异文对照、字词注释、概念索引、人工审核译注进度跟踪。
