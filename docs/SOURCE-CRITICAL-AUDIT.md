# 《传习录》原典可靠性纠错（2026-10-27）

## 严重质量警示

当前 data/volume-*.json 源自第三方 jeklau/chuanxilu@1910cd1 的现代 OCR 校改转录，**尚未与指定历史刊本逐字核对，不是可靠的古籍校定本**。原来的数千条测试断言只证明文件连号、字段存在、引文在同一份源转录内出现，根本不能证明文本与明刊本一致。此前将这类测试称为「原文可靠」属于方法错误，必须纠正。

## 已确认的独立外部差异

- 第三方源电子转录为卷上129段、卷中71段、卷下143段，共343片段；维基文库《傳習錄》相应分卷分别为129、71、142条，共342个现代编号。
- 维基文库卷下317条从「博学于文」问答延续至「先儒解格物」的长段；源CXL-0317和CXL-0318将其拆开。
- 因此源CXL-0319对应维基文库318，末尾CXL-0343对应维基文库342。当前不能再将343称为不加限定的「全书条目数」。
- 源316标记为「钱德洪录」，维基文库316则位于「此后黄以方录」标题之前；此处属于篇章归属待查，不宜直接判定哪种刻本绝对正确。
- 现有序跋目录与不同嘉靖刊本可能不一致，尚未核定底本。任何「准确无误、全本完成」声明都应停止。

**临时修复**：保留旧文本与编号，新增 data/concordance.js 对照表。映射1—317不变，源318映射参考317，源319—343映射参考318—342。此为编号关系，不是逐字校勘，未擅自改写原文且未破坏用户先前的链接。
