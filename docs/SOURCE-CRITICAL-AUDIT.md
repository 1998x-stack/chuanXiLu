# 《传习录》原典可靠性纠错（2026-10-27）

## 严重质量警示

当前 data/volume-*.json 源自第三方 jeklau/chuanxilu@1910cd1 的现代 OCR 校改转录，**尚未与指定历史刊本逐字核对，不是可靠的古籍校定本**。原来的数千条测试断言只证明文件连号、字段存在、引文在同一份源转录内出现，根本不能证明文本与明刊本一致。此前将这类测试称为「原文可靠」属于方法错误，必须纠正。

## 已确认的独立外部差异

- 第三方源电子转录为卷上129段、卷中71段、卷下143段，共343片段；维基文库《傳習錄》相应分卷分别为129、71、142条，共342个现代编号。
- 维基文库卷下317条从「博学于文」问答延续至「先儒解格物」的长段；源CXL-0317和CXL-0318将其拆开。
- 因此源CXL-0319对应维基文库318，末尾CXL-0343对应维基文库342。当前不能再将343称为不加限定的「全书条目数」。
- 源316标记为「钱德洪录」，维基文库316则位于「此后黄以方录」标题之前；此处属于篇章归属待查，不宜直接判定哪种刻本绝对正确。
- 现有序跋目录与不同嘉靖刊本可能不一致，尚未核定底本。任何「准确无误、全本完成」声明都应停止。

**临时修复**：保留旧文本与编号，新增 data/concordance.js 对照表。映射只是初始候选：85与86已确认位置对调；175—200附近拆合/错序尚待人工逐条复核；卷下317/318源片段对应参考317，源319—343暂映射为参考318—342。此为编号关系，不是逐字校勘，未擅自改写原文且未破坏用户先前的链接。

## 已运行的独立电子文本比对

于 GitHub Actions 以维基文库原始 wikitext 为第二电子文本，经繁简转换、去除参考脚注及标点后逐条比较，2026-10-27 的初步结果：

- 342条参考条目中，有**151条**可达到完全相同的汉字序列。
- **284条**的对应序号字符相似度达到至少98%，**20条**低于90%。这不是「20条被证明有错」；首先需要处理拆合与错序。
- 检测出**481个差异片段**（未经人工判定；包含异体、编辑改写、位置错配及源代码清洗误差）。
- 在现行数据中，**源85、86条与维基文库参考86、85存在对调**，两条可达100%汉字一致。
- 卷中177—195附近明显有多处段落拆合、前后错置，例如源184更接近参考185、源185与186都包含参考187的文字。**不能按数字直接配对**。
- 对卷下317的拆分证据仍然成立。

最新机器比对工件：[External text witness audit](https://github.com/1998x-stack/chuanXiLu/actions/runs/40485489875)（含逐条CSV、JSON、30个差异重点及候选重排表）。

**特别注意：** data/concordance.js 是保留旧ID的临时编号索引，包含源85/86对调和卷下317合并。卷中175—200范围内显示「对照编号待核」，不可将数字映射误认为已经证明。未逐字比较古籍明刻本影像，不得给单条设为verified。

## 尚未做的必要工作

1. 对全部342个参考条目取 **独立版本** 的文字，而非同源派生；逐条记录 source_version、revision、witness_page、quote_span。
2. 与明刊本影像比对，记录所有异体字、OCR误识、漏文、增文、断句和误置篇章；区分「真实传本异文」与「转录错误」。
3. 每一个修正文必须留可复现的差异、照片叶页、审核者、审核时间；完成前 verification 必须 pending。
4. 现代释读与原文分开，特别核查来书引用、弟子问句被错误归给王阳明的风险。
5. 前端引用需区分「旧电子片段号」「对照本参考号」和真正的古籍刊本卷页。

## 审核准则

可以报告「编号映射可核对」，**不可以报告「全文古籍校勘完成」**；即便维基文库与第三方电子稿相同，也只意味着两份转录一致，仍需可靠刊本影印验证。
