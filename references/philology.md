# 文献学说明：语录体、书信体与电子编号

《传习录》今通行分上、中、下三卷。上卷主要为早期语录；中卷多为王阳明论学书信与教约；下卷为后续弟子记录及序跋。不同整理本收录、分段、标点、卷末附录会有差异。

目前收录源采用固定转录仓库 jeklau/chuanxilu@1910cd1，按照其条目顺序生成 CXL-0001..0343。卷边界为1—129 / 130—200 / 201—343。记录准确的是这一数字转录版本，不应外推为所有刊本的统计。

项目应建立以下后续字段：
- edition: 明刻本或有明确出版信息的整理本；
- witness_id: 校勘见证本唯一编号；
- original_graph: 字形与异体字；
- punctuation_editor: 标点提供者；
- variant_readings: 具体异文与位置；
- audited_by / audited_at / audit_evidence: 校审证据；
- relation_to_other_editions: 与他本的跨版对齐关系。

读者界面应允许未来按不同底本切换，避免把后人标点和段落拆分当成唯一权威解释。当前优先展示逐条来源和校勘状态。
