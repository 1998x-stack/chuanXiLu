# 引文核验与出处规范

## 固定路径

data/volume-1.json = 卷上 CXL-0001 至 CXL-0129；
data/volume-2.json = 卷中 CXL-0130 至 CXL-0200；
data/volume-3.json = 卷下 CXL-0201 至 CXL-0343。

每条使用：id（稳定电子编号）、number（数字序号）、volume（上/中/下）、section（篇章）、text（电子转录）、sourceFile（转录来源）、verification（校勘状态）。当前全部 verification=pending。

引用格式：「知而不行，只是未知。」——《传习录·卷上·徐爱录》（本项目 CXL-0005）。

**必须强调**：CXL 编号只是本项目的电子索引，不是明代原版的原生章码。现代某些「第 N 条」体例也会有不同拆合。本项目源是固定提交的转录文本，仍需核实刊本。

- CXL-0005 卷上·徐爱录：「知而不行，只是未知。」

- CXL-0115 卷上： 「种树者必培其根，种德者必养其心。」篇名从该条 section 字段读取，不能凭记忆补写。
- CXL-0288 卷下： 「良知只是个是非之心。」篇名从该条 section 字段读取。

## 审核清单

1. 在相应 JSON text 中逐字查到拟引用字句。
2. 检查引语属于哪位说话者；是弟子问句还是先生答句。
3. 检查所在篇是语录、论学书信，还是序跋、后人附记。
4. 对照相邻句了解答问背景，避免硬摘片语反向推导。
5. 需严格校勘时对照明确版本、卷页、异文及影印扫描，记录字形和标点差异。
6. 释义必须是独立标注的现代解释，不可伪装为古文。
7. 核不出原文、不确定作者或篇名时，应坦言无法确定。

## 易犯错误

把「知行合一」当成一句具体古文；用「事上磨炼，方为学问」之类后人概括冒充逐字原文；将现代编辑标题误认为王阳明原有篇名；用内省主义替代证据主义。以上均须避免。
